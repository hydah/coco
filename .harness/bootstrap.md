# coco

coco 是基于 State Threads 的 C++11 网络库。`AGENTS.md` 指向本文件，会话从这里进入。

## 文档

设计文档和给代理的约定都在 `.harness/`：

- [编码与审查](development.md)：编码前列不变量和反例，修改后先跑定向检查，完成前检查退出路径、交错和资源收拢。
- [设计文档](docs/README.md)：构建、架构、协程、State Threads、TLS。改对应行为时一起改。
- [测试](testing.md)：改了构建、运行时、网络、TLS 或 CMake 之后，说完成之前要跑完的环境。

## 约定

- 沿用仓库里已有的风格、分层和接口，不另起一套。
- 改运行时、协程、线程、网络或 TLS 行为前，必须先读 [编码与审查](development.md)，写清适用风险、预期行为和能推翻实现判断的定向检查；首次实质修改后立即验证。
- 取消、完成、错误是不同事实；完成前按 [编码与审查](development.md) 核对关键交错与每条退出路径，给出具体断言和审查结果。覆盖率和 sanitizer 通过不能代替这些证据。
- 公共行为变了，同步改对应文档和示例。
- 没按 [测试](testing.md) 跑完，不要说已经完成。结论里写清每个环境的结果，以及哪一项没跑、为什么。
